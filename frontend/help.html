Guide

Ask one question at a time

Type a mathematical question into the workspace, or choose one of the examples. Include the numbers and any units. Select Solve problem, or press Ctrl + Enter (⌘ + Enter on Mac).

Read and check the solution

The answer appears below your question, together with the time it took. Ask for “only the final value” when you need a short answer, or “show the steps” for an explanation. The first question can take longer while the model starts.

Keep a useful answer

Select Copy answer to copy the solution. Generated answers can be wrong: check the calculation and reasoning, especially for unfamiliar problems.

When something goes wrong

An empty question shows a message without submitting it. If the service is unavailable, wait a moment and retry. If it stays unavailable, ask the operator to check the local services. For long waits, try a shorter question.

Explore the pipeline

The Pipeline screen shows the stages behind the assistant, their status, elapsed time, data counts, quality checks, and execution logs. Its tool links open the local MLflow experiment tracker and monitoring dashboards.

Privacy

Inference runs on this computer. The application does not save the question text in its request logs. The initial operator setup downloads the public dataset and base model; answering questions works locally after setup.
